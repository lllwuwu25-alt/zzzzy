# 题目表格排版

## 行为

- AI 提取普通数据表时，要求在题干或答案字段中逐行保留表头、分隔行和数据，不改变数值、未知量和列顺序，不求解缺失答案。
- 识别建议、题干和答案预览、详情页及复习页使用真实 HTML 表格；公式继续使用本地 KaTeX。
- 兼容已保存的 `| 表头 | 值 | |---|---| | 甲 | 6 |` 单行格式，只修正显示，无需重新识别。
- 有表格时默认展示排版，点击“编辑题干文字”可切换到逐行源文本修改，再切回排版。列表和退卡动画不显示表格管道符。
- 选择题的表格选项支持排版预览、逐行编辑，作答前即可看到表格，通过选项标题行选择答案；揭示后保留相同表格结构。
- 不支持用普通 Markdown 表达的复杂合并单元格继续保留原表配图；没有引入任意 HTML 执行。

## 验证

- 初始回归测试针对用户提供的单行频数表，旧实现没有生成 `<table>`，测试失败；新实现显示 2 列、5 行数据且未知量 `a` 不再显示反引号。
- 单元测试覆盖普通/单列表、对齐、空单元格、多表与前后段落、公式/代码中的竖线、转义竖线、中文与 emoji、无效格式及 HTML 安全。
- 审查后新增失败回归复现连续单行表格误合并、表格选项未排版问题；修复后验证两张表保持独立，选项表格不嵌套在标题或标签元素内。
- 独立浏览器使用模拟 AI 响应验证识别建议、采用、源文本编辑、保存、详情、复习、答案内分数和 390px 窄屏；不调用真实付费服务，不向用户的题库写入测试内容。
- 浏览器额外验证表格选项逐行修改、保存、复习选择和答案揭示，覆盖 1280px 与 390px 窗口。
- 选项识别建议中的字母与正确标记单独展示，避免破坏表头及数据行。
- `npm test`：60 项通过。`npm run build` 通过；保留已有的单包体积警告。
- `node scripts/qa-question-tables.mjs`、公式、复习卡片回归通过；模拟 AI 仅验证显示与数据流程，不代表真实模型识别准确率。
