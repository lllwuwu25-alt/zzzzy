# DeepSeek 工作台测试预览

此版本为开发预览，未打包、未发布、未推送 main。开发分支 codex/deepseek-workbench。

## 已验证

- TypeScript 生产构建通过，前端测试 47 项通过。
- Rust 请求内容、非法/截断响应、取消登记、图片导入及本地写入测试通过；release 编译检查通过。
- 独立 Chrome 会话验证五个页面，1024/760/390 宽度无横向溢出，减少动效设置生效。
- 模拟 DeepSeek 请求：确认前不调用 API，确认后一次调用，采用/撤销建议、完成整理可用。
- 模拟一次存储容量错误后继续编辑，完整草稿恢复写入，未保存内容不会丢失并误报成功。
- 阻断全部外部网络，OCR 识别出 MATH 12345，置信度 91，外部请求数 0。
- 新浏览器会话默认空题库，测试资料仅在自动化独立浏览器上下文中写入。
- 独立代码审查后修复保存失败恢复、完成整理期间写入次序、图源/题型变化后旧建议失效、准备请求期间取消竞态。

## 待真实环境验证

- 未提供真实 DeepSeek API Key，未进行付费 API 请求；视觉识别准确率、真实余额/限流错误需用户测试。
- 系统凭据库锁定/拒绝写入、Finder 原生拖入及 Windows 桌面人工流程未实测。Rust 编译测试不能代替这些人工测试。
- 网页预览密钥只在当前页面会话的内存中存在，刷新消失；浏览器跨域策略可能影响真实 API 使用，桌面版经 Rust 发起请求。
- 200% 缩放按窄视口检查布局，不代替所有操作系统 DPI 组合。

## 测试方式

本地运行 npm run dev -- --host 127.0.0.1，打开 http://127.0.0.1:5174/ 。
设置 → AI 辅助识别 → 启用、填写自己的 DeepSeek API Key、保存；测试连接会发送合成测试图并可能计费。
收录图片 → 分组与题型 → 收集箱 → AI 辅助识别 → 检查发送范围 → 发送并识别 → 检查并采用字段 → 完成整理。

自动化脚本 scripts/qa-workbench.mjs 使用网络拦截模拟 API，不调用付费服务；scripts/qa-offline-ocr.mjs 阻断外网测试本地 OCR。
