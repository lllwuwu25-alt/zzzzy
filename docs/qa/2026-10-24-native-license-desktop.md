补测发现并修复：第一次签发已提交、文件导出失败时，窗口名额原先不刷新。真实 Electron 回归先失败，刷新脱敏账本后通过；用户可直接从设备列表重新导出原证书。

打包修复：Node 默认复制会把 Framework 相对链接转成依赖源目录的绝对链接，导致代码签名失败。新增“删除源目录后复制包仍可读”的回归，使用原样相对链接复制后通过。保留 Electron/Chromium 许可说明，商家包签名校验通过。

数据隔离补查：旧版 DeepSeek Keychain 服务名固定，独立测试标识并不会自动隔离该凭据。增加回归先失败后通过：正式 `local.mistake.notebook` 保留原服务名兼容老密钥，测试版及其他标识使用自己的服务名。未访问或修改真实系统凭据。

## 原生买家窗口与人工边界

买家 release 已完成。首次依赖编译耗时 11 分 42 秒；凭据隔离修复后重新构建耗时 1 分 43 秒。交付的是第二次构建，第一次产物已移出交付目录。最终源码无首次构建时的临时未使用函数警告。

- 两个最终 `.app` 均通过 `codesign --verify --deep --strict`；都是本地 ad-hoc 签名，不是 Developer ID 公证。
- 两个 `.dmg` 均通过 `hdiutil verify`。沙盒内创建磁盘映像失败后，经批准使用系统工具完成创建，没有用 zip 冒充安装包。
- 已用 LaunchServices 打开实际买家测试 `.app`，进程 `mistake-notebook` 持续运行；独立目录 `~/Library/Application Support/local.mistake.notebook.localtest` 从不存在变为已创建且为空，没有题库文件或激活文件。未向其预置或写入任何题目，未触及正式应用目录。
- 买家 Info.plist 标识与名称分别为 `local.mistake.notebook.localtest` / `错题本本地测试版`。Resources 中仅有图标（前端嵌入二进制），没有商家代码；二进制私钥扫描通过。商家 app 资源只含固定业务代码/UI 白名单，无保险库、证书、测试资料。
- 所有 `ctb-local-build-*` 临时构建目录均已清理，随机测试私钥未保留。仅本机测试授权单独位于交付目录，不在 App 或 DMG 内。正式公钥仍留空。

当前工具没有可用的原生 macOS 窗口交互通道。以下项目需要用户在实际买家窗口手动验收，不能据 Rust/浏览器测试推定为完成：首次页面和机器码显示、系统另存为、无效/有效授权导入、重开后的激活状态、拖入图片/保存/重开、原生 WebView 的 Logo/侧栏动效。正式对外售卖前仍须对应平台实机测试。
