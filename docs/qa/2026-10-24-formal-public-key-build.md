# 正式公钥配套本地构建

日期：2026-10-24。仅本地 Intel Mac 构建；未合并 main、推送或公开发布。

## 输入与密钥边界

用户提供 `license-public-key.json`，格式为 version 1 / Ed25519 / product `mistake-notebook`。仅读取该公钥文件，没有读取其旁边的保险库、备份或密码，没有生成或导出正式私钥。

正式公钥已写入 `src-tauri/license-public-key.json`，公钥标识（SHA-256 前 16 位）为 `a6989c8778c6d947`。卖家后续必须使用生成此公钥的同一份主保险库发码；不能使用临时测试保险库，不能把临时测试授权与正式公钥包混用。

## 仍需商家本人验收

未自动启动正式应用，避免读取或影响本机已有正式错题本资料；也没有向正式应用目录写入授权文件。

由于正式私钥仅由用户持有，本轮没有代替用户签发正式授权。下一步应由用户安装/打开上述“错题本”，复制机器码，在同一主保险库中新建“本机激活验收”购买记录并签发，再导入正式授权、重开检查。建议不要占用真实顾客的购买记录。

授权通过后继续检查图片拖入、整理、批注、复习和备份。原生激活交互尚未验收，不能把密码学自动化当成该步骤已经通过。

macOS 为 ad-hoc 本地签名，未做 Developer ID 公证；这不是三平台公开发行完成的结论。Windows/Apple Silicon 产物不在本轮，需后续对应构建与实机测试。
