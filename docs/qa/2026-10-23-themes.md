# 五款工作台皮肤验收

## 使用

在「设置 → 外观与动效 → 工作台皮肤」选择墨青、雾白、暮紫、夜读或彩绘。选择后立即生效，刷新或重启恢复当前设备偏好；不随题库备份迁移。无法写入偏好时显示说明，本次会话仍然生效。

彩绘仅使用分色导航、轻微不对称圆角和柔和彩色卡片背面，不为题目原图、批注颜色或表格正文添加滤镜、噪点与纹理。

## 验证范围

- Vitest：五个主题 ID、偏好校验、写入失败反馈、即时 DOM 应用、颜色模式与元信息、独立 WCAG 相对亮度计算、五项可访问 radio 渲染。
- Playwright `scripts/qa-themes.mjs`：隔离题库内检查五种皮肤的设置、今日复习、复习卡片/答案、全部错题/详情、复习记录、收集箱、图片批注器与导入选择框。
- 对已覆盖页面的可见正文执行 computed-style 对比度检查；禁用控件、装饰缩略预览与图片像素不作为正文。正文/次要文字/按钮 ≥4.5:1，原图与画布保持原色，原始 dataUrl 不变。
- 主题刷新记忆、键盘方向键选择、390px 窄屏、200% CSS 界面缩放、系统 reduced motion、偏好存储拒绝写入及跨页面保留。
- 回归表格、公式编辑、复习卡片、AI 字段采用/撤销。使用模拟 AI，不调用付费接口，不向用户浏览器题库写入测试内容。

## 发布范围

仅本地预览。没有打包、推送、合并 main 或发布；原有大于 500kB 的构建体积提示仍存在。本轮不验证原生 Windows/macOS 安装包及系统窗口标题栏。

## 当前结果

64 项 Vitest、TypeScript/Vite 构建、五皮肤浏览器验收及表格、公式、卡片、模拟 AI 回归通过。五种首页、外观设置、复习卡片截图已人工查看；截图及合成题目未加入应用资源。
