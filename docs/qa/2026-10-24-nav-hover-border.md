# 导航选中项悬停边框修复

## 原因与修复

导航选中背景和边框在 `.nav-selection`（z-index 0）上，导航按钮位于其上方（z-index 1）。主题悬停样式给选中按钮添加了不透明背景，覆盖底层边框；彩绘主题上下直线消失、两侧弧线残留最明显。

仅让选中导航按钮的悬停背景透明，继续使用底层选中背景和完整边框。不改变导航布局、圆角、选择动画、主题色或键盘焦点；非选中按钮仍有正常悬停反馈。

## 回归验证

- 新增 `scripts/qa-nav-hover.mjs`，在真实 Chrome 渲染截图中采样选中项上下边线的中央区域，而非仅检查 CSS 字符串。
- 修复前：彩绘 hover 顶边 0/96 个像素匹配边框色，测试明确失败。
- 修复后：彩绘、墨青、雾白、暮紫、夜读五款主题的 idle/hover 上下边线均有 >90% 采样点匹配，非选中项悬停背景仍变化。
- 人工查看修复后的彩绘侧栏截图，边框完整。
- `npm test`：75 Vitest + 30 Node 测试通过。
- `npm run build`：通过；原有主 chunk >500 kB 建议仍存在。
