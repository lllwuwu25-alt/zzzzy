# 今日复习叠卡预览

首页先显示今日复习入口，可按科目选择到期题目。点击开始后进入叠卡界面，完成四档评分之一后，卡片退到后方并计入已完成；暂时跳过只轮转待复习队列，不写评分。全部完成后显示卡片归位与勾选动画，以及“今日复习已结束”。支持撤销本轮最近一次评分、返回选择、减少动效与窄窗口。

验证：npm test 49/49、npm run build 通过。scripts/qa-review-deck.mjs 在独立 Chrome 中模拟首次评分存储失败，确认卡片保留；重试后依次完成、跳过、撤销、重新评分，最终仅 3 条复习记录、每题 reps=1。390px 下无横向溢出，减少动态效果可用。测试题仅写入独立浏览器上下文，不进入应用初始数据。
