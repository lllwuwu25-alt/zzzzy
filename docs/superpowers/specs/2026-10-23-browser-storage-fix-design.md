# 网页图片保存修复

用户已确认修复网页预览中图片创建错题失败的问题。实测旧流程把全量题目与 Base64 图片写入 localStorage，大图会触发 QuotaExceededError。

## 目标与约束

- 网页使用原生 IndexedDB 持久保存完整 notebook JSON，不再向 localStorage 写入题目。
- 首次启动优先读取 IndexedDB；没有记录时读取、校验并迁移旧 localStorage，旧值保留为只读备份。
- 保存成功以数据库事务提交完成为准，失败不创建半成品记录，原图不压缩、不修改。
- 初始化失败或数据损坏时阻止打开空题库覆盖已有数据，提供重试读取和可恢复的错误说明。
- 浏览器额度不足、权限被禁用、数据库被占用分别提示；不笼统解释成磁盘不足。
- 桌面端原生文件保存路径不变；不打包、不发布。

## 方案

继续用 localStorage 压缩图片仍有总量限制，并会改变原图。网页直接保存到用户文件夹会增加权限与兼容要求。采用 IndexedDB，沿用现有数据结构和备份格式，可保持改动集中。

## 验证

真实浏览器测试旧数据迁移、大于旧存储额度的 PNG 导入、刷新恢复、失败后重试、不重复创建、损坏记录不覆盖。回归 AI、复习评分、公式和配图；运行完整前端测试与生产构建。
