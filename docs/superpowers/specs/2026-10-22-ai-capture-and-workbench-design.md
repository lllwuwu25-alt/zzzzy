# AI 辅助录题与学习工作台升级

状态：用户已确认整体方案，并指定首版支持 DeepSeek；尚未开始产品代码实现。

## 目标与已确认约定

用户希望更容易从图片记录错题，并升级整体界面与动效。已选择“本地 OCR + 可选联网 AI”，首版仅支持 DeepSeek，由用户配置自己的 API Key，发送图片前明确说明接收方。

延续墨蓝绿色、安静清晰的学习工作台。保留今日复习、收集箱、全部错题、复习记录、设置五个入口，以及多图先分组、后选择题型的流程。识别内容供用户检查后保存；图片没有提供的答案保持为空。

## AI 接入

首版实现 DeepSeek 官方 Chat Completions 视觉接口适配器。官方基础地址固定为 `https://api.deepseek.com`，默认模型 `deepseek-flash`，用户填写自己的 API Key。模型名可在高级设置修改并通过视觉连接测试验证；首版不提供其他供应商或自定义服务地址。使用 `user` 消息中的 `image_url` base64 输入图片，以及 `response_format: { type: 'json_object' }`、含 JSON 示例的识别提示，响应在本地解析并验证字段结构。关闭 thinking 以减少录题等待，输出长度限制为 8192 tokens；遇到截断或空内容提示重试，不自动重复付费请求。

上述视觉模型、请求格式和 JSON 参数于 2026-10-22 核实：[官方图像理解文档](https://api-docs.deepseek.com/guides/vision/)、[官方 API 调用说明](https://api-docs.deepseek.com/quick_start/pricing)、[官方 JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)。模型能力后续变化时以连接测试与官方文档为准，不用文本模型冒充视觉识别。

默认关闭联网 AI。完成配置仅表示可使用，导入图片仍先在本地保存并运行 OCR。用户主动点击“AI 辅助识别”才准备发送，不做后台上传、不在本地识别失败时自动转为联网。

设置默认只显示 DeepSeek、密钥、测试连接；官方地址以只读信息显示，模型名收进高级设置。测试连接发送合成的极小测试图片以验证视觉输入及结构化输出，按钮旁明确说明会调用 API 并可能计费，不使用用户题目。错误区分密钥无效、余额不足、模型不支持图片、网络错误、限流、超时与返回结构不兼容。

桌面版由 Rust 发起请求，API Key 使用系统凭据库保存；保存失败显示真实原因，不降级写入明文。普通配置与密钥均不进入错题备份或工作区文件夹。预览网页仅允许会话内使用密钥，并解释服务跨域限制；不向 localStorage 写密钥。

桌面请求仅发送到固定的官方 HTTPS 接口，不接受前端传入任意地址；请求不跟随跳转，防止凭据被转发到其他域名。错误及日志不含密钥、完整请求体和图片。变更模型后要求重新测试，发送确认始终展示当前模型。

## 图片发送与结果检查

1. 用户在当前题点击“AI 辅助识别”。配置缺失时打开设置入口并保留当前编辑草稿。
2. 显示本次发送说明：服务主机、模型、当前题图片数量、将发送图片与已识别文字。只发送当前题选定图片及其 OCR 文本、题型，不附带整个错题本、笔记或历史记录。首版每次发送均需要用户点击“发送并识别”。
3. 本地生成适合识别的图片副本，长边不超过 2400 像素；单次最多 8 张、压缩后合计不超过 12 MB。超限时要求分批选择图片。原图、批注及裁剪记录保持原样。GIF 使用首帧，答案遮挡不会被当成原图内容发送。
4. 显示真实阶段：准备图片、等待服务响应、整理结果；不展示虚构百分比。支持取消，90 秒超时；取消或切换题目后，迟到结果不得写入其他题目。失败保留本地 OCR 和编辑内容，提供重试。
5. 结果在编辑区内以待检查建议展示：题干、选项、答案和解题要点。每个字段可单独采用，可一次采用全部建议，也可放弃；采用建议只更新草稿，完成整理仍由用户操作。
6. 请求期间允许编辑。结果基于发起时的字段快照生成；有变化的字段显示冲突提示，一键采用跳过冲突字段，用户可单独比较后替换。采用后的变更可以撤销，不能恢复请求前整张表单而丢失无关编辑。

选择题保留单选/多选、选项顺序和答案引用；填空题逐空整理，缺失答案留空；简答题整理参考答案与图片明确给出的要点。AI 不推导缺失答案、不补写错因、不自动创建分类。题型建议与用户选择不同，仅提示，不擅自转换数据。

识别来源区分“本地 OCR”和“联网 AI”，展示服务模型与识别时间；所有 AI 输出均标记为“待核对”，不使用模型自报置信度伪装准确率。错误字段或无法验证的答案引用不自动套用，显示可理解的校验提示。

## 界面布局

### 整体框架

保留当前品牌色和系统字体，统一背景层、面板层、分隔线、输入框及按钮状态。左侧导航提供清楚的当前页标记与收集箱数量；顶栏保留页面标题与收录入口。桌面可折叠为图标导航，窄屏使用抽屉。常用操作不依赖悬停才能发现。

### 收集箱与编辑

桌面采用紧凑题目列表、原图预览、编辑内容三部分。原图支持缩放和打开批注，编辑区集中显示题干与当前题型字段，底部固定保存与继续。分类、错因、笔记、标签按需展开。AI 建议以内嵌比较区出现，不增加永久侧栏，不堆叠弹窗。中等窗口合并图片为可展开预览；窄窗口以“图片/内容”标签切换，保留草稿与滚动位置。

### 其余页面

- 今日复习：强化当前题目和显示答案/评分主操作；队列作为次要上下文，可折叠。答案与评分区过渡不改变键盘操作顺序。
- 全部错题：保留层级、全文搜索、组合筛选；统一筛选控件和选中状态，列表预览信息精简。
- 复习记录：按日期分组，清楚展示题目、评分及时间；单条展开查看作答与调度变化。
- 设置：分为工作区、复习周期、AI 辅助识别、备份与回收站。AI 未配置与离线状态都有明确可操作提示。

涉及上传承诺的文案全面核对：默认说明“资料保存在本地”；AI 入口说明“确认后将选定图片发送至所配置服务”。移除在联网 AI 场景下仍声称“永不上传”的绝对文案。

## 动效规范

延续用户之前确认的克制高级方向，主要状态过渡 150–250ms，按压反馈 80–120ms，无弹簧、无循环装饰背景。主体验为识别完成后，建议与对应字段建立清楚的视觉关系，采用时短暂强调目标字段。

- 导航切换：选中底板平滑跟随；内容采用轻量过渡，直接进入可操作状态。
- 导入分组与题型切换：连续面板过渡，保留前后选择与焦点。
- 展开、抽屉：短距离移动和透明度过渡，关闭时恢复焦点。
- 按钮：统一颜色、轻微位移和图标反馈；保存成功仅在真实持久化完成后反馈。
- AI：阶段文字、等待指示、结果出现和字段采用反馈，不逐字模拟输出、不持续扫描原图。
- 复习：揭示答案、评分后进入下一题具有连续反馈，不以动画延时阻挡输入。
- 拖入：投放区强调、导入完成定位到新题；长列表不逐项延迟出现。

优先使用 CSS 和 Web Animations API；确有共享布局需要时才引入额外动效依赖。尊重 prefers-reduced-motion，增加应用内“跟随系统/减少动效”设置，减少模式用即时状态或淡化替代位移。动画不负责解锁功能、不依赖动画结束才能保存或切页。

## 实现边界

从 App.tsx 提取收集箱编辑器、设置与识别建议组件；只进行本次界面与识别流程所需的拆分。建立识别适配器、AI 输出校验、字段建议合并、请求取消和凭据命令的独立模块。旧 notebook.json 保持可读，新增来源信息为可选字段。

密钥和服务配置为设备级数据，备份恢复不改变设备 AI 配置。题目的识别来源可随备份保留，但不含服务密钥。初始安装保持空白资料，不携带开发测试题。

此次不增加聊天助手、AI 自动解题、云同步、内置付费代理或本地大模型下载。先交付可测试预览与桌面验证结果，打包发布需后续明确安排。

## 验证与验收

- AI 默认关闭；导入、粘贴和拖入仅本地处理，开启配置也不会自动发送。
- 三类题型、缺失答案、多图顺序、非法 JSON、无效答案引用均覆盖结构校验测试。

- API 密钥不进入工作区、备份、日志或前端持久存储；系统凭据保存与删除失败可见。
- 验证连接仅发送合成测试图；正常请求仅含明确选择的当前题资料，确认中显示实际接收主机。

- 五个页面在 1024px、1440px、窄窗口与 200% 缩放下检查布局、焦点、中文长标题和错误状态。
- 检查键盘访问、焦点恢复、WCAG AA 对比度、系统与应用减少动效设置；不以颜色单独表示状态。
- TypeScript 构建、现有测试、AI 协议/合并测试、Rust 请求与凭据边界测试通过。真实服务和 macOS/Windows 人工验证与模拟测试分开记录，不把 mock 通过宣称为端到端成功。
