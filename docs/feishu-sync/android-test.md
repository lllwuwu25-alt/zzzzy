# 安卓测试版：HONOR 90 / Android 15

这是现有错题本的 Tauri Android 版本，不是新建的演示程序。使用独立应用 ID `local.mistake.notebook.androidtest`，不覆盖正式桌面版，也不代表已完成商用手机授权。

## 安装

1. 在本次 GitHub Actions 构建页面的 **Artifacts** 下载安卓测试附件（GitHub 通常要求登录）。解压后选择中文名称、后缀为 `.apk` 的文件，不是源码包。
2. 将 APK 发送到荣耀手机，在文件管理中打开，按系统提示允许该来源安装。此包为调试签名测试版，不是商店发行版。
3. 本机未配置同步服务时，进入“先测试本机录题与复习”。不要把“未配置”当作已同步。

每次 CI 当前使用临时调试签名；后续测试包可能不能直接覆盖安装。**不要直接卸载**：先导出完整备份并检查文件，再决定是否卸载重装。正式版本需要部署人员配置长期发行签名，私钥不得进入公开仓库。

## 本机验收顺序

1. 相册录题：单张、多张、取消选择；检查分组和题型选择、题干与选项编辑。
2. 拍照录题：首次相机权限、拒绝后重试、系统相机取消；检查原图清晰度。
3. 图片批注、撤销/重做、保存并重开；复习卡片及评分、撤销、复习记录。
4. 飞行模式创建与编辑题目，杀掉应用并重开，确认本机内容还在。
5. 设置 → 备份与恢复 → 导出到系统文件夹，验证导出的 JSON 和图片，再测试恢复。卸载或清除数据会删除私有目录内的本机资料。
   云同步区域的“查看 / 导出同步前备份”可选择原生自动快照再导出；读取损坏时恢复页也提供此入口。自动快照包含原始本机空间与待同步数据，请妥善保管，不公开发送。
6. 系统大字体、横竖屏、键盘弹出、系统返回键、低空间和相机权限关闭。

Android 原生层使用应用私有文件夹保存 Notebook v1，沿用临时文件写入及替换；不索取“管理所有文件”。相册使用系统文件选择器，拍照通过系统相机。API Key、产品会话与设备凭据通过 Android Keystore AES-GCM 加密保存，不写入错题备份；读取失败不会降级为明文。

## 真实双端同步前，部署者必须完成

1. 按 [developer-setup.md](developer-setup.md) 配置自有飞书应用、测试租户权限、后端私有环境和可被手机访问的 HTTPS 域名。手机 APK 不需要网站承载业务界面，但 **OAuth 回调与同步网关仍必须在线**。
2. 本次安卓测试要求 `PUBLIC_APP_URL` 和 `API_PUBLIC_URL` 使用同一 HTTPS origin，保证扫码白名单一致。回调地址是 `/v1/auth/feishu/callback`；原生登录回调只显示“返回错题本”，不跳转到手机网站。
3. 在仓库 Actions Variables 设置公开的 `SYNC_GATEWAY_URL`（如 `https://sync.example.com`，不是 App Secret），重新运行本分支工作流。普通用户不填写任何开发参数。
4. 使用相同测试网关地址构建电脑端，在电脑连接飞书、自动建库，然后“添加设备”生成二维码。
5. 手机用 App 内“扫描电脑绑定二维码”（可粘贴电脑复制的链接）→ 浏览器完成同一飞书账号 OAuth → 返回 App → 在电脑确认手机 → 手机首次同步预览、下载图片。
6. 测试两端编辑冲突、离线队列、软删除、账号切换、撤销设备和授权刷新。未确认设备不能读取题库；仅扫描二维码不构成授权。
