# 普通用户操作说明

测试范围由部署人员设置。你不需要创建应用、复制表格 ID 或填写 App Secret；如果看到“云同步尚未开放”，请等待服务配置，仍可正常使用本地功能。

## 电脑连接

1. 打开现有错题本 → 设置 → 云同步，阅读资料去向说明。
2. 点击“连接飞书”，在系统浏览器中登录并授权。拒绝或取消不会删除本机题库。
3. 回到错题本。系统检查身份及权限，自动创建/恢复自己的飞书题库与表结构。
4. 查看首次同步数量预览。确认后系统先保存完整本地备份，再进行非破坏性同步。
5. “已同步”表示当前必需操作和附件均被服务确认；“图片等待上传”“等待上传”“存在冲突”都不是完成状态。

如果权限或可用范围受组织限制，联系管理员按部署说明完成审批，不要把个人飞书密码或开发者密钥发给其他人。正式跨企业开放仍待平台流程，不保证所有飞书个人账号均可使用本测试应用。

## 添加手机或另一台电脑

1. 已加入的电脑点击“添加设备”，显示 5 分钟绑定二维码，也可复制短期绑定链接。
2. 手机打开错题本 Android App，用 App 内扫码入口扫描，用**同一飞书身份**登录。若是新设备，登录后仍在等待区，不能读取题库。没有相机权限时，可粘贴电脑复制的短期绑定链接。
3. 原电脑显示待加入设备，核对后点“允许这台设备”。不认识的请求请拒绝；刷新二维码会作废旧请求。
4. 手机确认加入后，进入首次同步并下载题库。可拍照或选图录题、编辑、搜索、复习。
5. 未缓存的题图会显示“原图尚未下载”，点击下载；也可在设备与本机副本中下载整套题库图片。完成并检查足够空间后，可离线查看已下载原图及批注。

切勿把绑定二维码长期贴到公开群。它不含飞书 Token，但属于短期认领凭证。App 或可选网页被系统挂起后不承诺持续后台同步，重新打开、回到前台或网络恢复会继续。

## 账号、离线与冲突

- 断网时继续本地录题、编辑、复习；手机请勿卸载或清除应用数据，可选网页请勿清空网站数据。未上传内容没有云端副本，需定期导出备份。
- 导出完整备份前先下载全部原图；若仍有云端原图未缓存，程序会明确阻止假“完整备份”。同步前自动备份可从云同步底部查看或导出。离线缓存的副本不能替代设备外备份。
- 网络临时错误采用有限退避。权限失效、结构变化和自动重试达到上限会暂停，修复后手动恢复；不会高频重复请求或删除队列。
- 两端修改同题时，保留本机与云端版本。按实际内容选择本机、云端，或题目保留两份；采用本机仍基于最新修订提交。
- 两端离线复习的历史都保留；复习安排有分歧时需要选择，不会静默丢掉另一端的事实记录。
- 删除进入回收站并同步墓碑；恢复产生新修订。启用同步期间本版不自动物理清理墓碑和原图。
- 切换到另一账号时会阻止自动上传。明确点击“备份并切换独立空间”后，原账号题目和待上传队列保留在原空间；不会复制到新账号。回到原账号可恢复其空间。

## 退出、撤销和恢复访问

- 暂停同步仅影响当前设备。退出时可以保留副本；仅在没有待同步内容或冲突时，才允许明确清除此应用的当前副本。清除前自动保存本机快照，云端、可见工作区和自动备份不被删除，也不是安全擦除。确认前建议导出完整备份。
- 设备列表可以查看并撤销其他设备。撤销立即禁止后续云访问，但不能保证远程擦除已缓存的离线副本。
- 断开飞书影响账号全部设备，暂停同步并清理网关授权/会话关联；不会删除飞书题库或本机资料。飞书平台侧授权撤销能力尚未接入，若需完全撤销请在飞书管理页面操作。
- 旧设备不可用时，在等待确认页选择“恢复访问”，明确确认撤销旧设备，再完成一次新的飞书授权。服务核实相同身份和原题库管理权限后，原子撤销旧设备、激活新设备；不冒称额外的多因素认证。失败会保留原状态。

## 错误时先做什么

先保留本地资料和备份，再查看云同步下的脱敏诊断代码与 request_id 发给支持。不要发 App Secret、完整 Token、授权码、二维码凭证或原题内容。单图超过 20 MiB、单条编辑信息超过 16 KiB、本次创建结果未知等限制不会通过重试消失，请按提示缩小副本或由部署人员核对；原图始终保留。
