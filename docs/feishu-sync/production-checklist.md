# 正式发布与仍需补齐的项目

**当前结论：仅供拥有者受控 staging 联调，不满足公开销售云同步功能的发布条件。** 不得因本地测试通过就改成 production；代码明确拒绝该环境。

## 真实测试前需要拥有者完成

- [ ] 按 developer-setup 创建自建应用、申请 `offline_access bitable:app`、登记固定回调、发布并批准可用范围。
- [ ] 将 App ID/Secret、测试租户白名单和两个不同强密钥只填入服务器私有环境。不要发到聊天或仓库。
- [ ] 提供持续运行、手机可达的 HTTPS 网关、可靠持久磁盘；不能依赖电脑开机，PWA 仅为可选入口。
- [ ] 准备 Intel Mac、HONOR 90 / Android 15 实机及至少两个测试身份，明确可用范围和套餐额度；原 HarmonyOS 5+ 范围不视作已支持。
- [ ] 为现有真实题库完整备份；首次联调先用可删除的测试资料，不复制客户题库做演示数据。

## 代码/交互仍未完成的边界

- [ ] 大于 20 MiB 的分片与恢复任务；目前明确拒绝，不是假续传。
- [ ] 大型笔迹/题干超过 16 KiB 的可同步存储迁移；目前本地保存完整，但任务失败并可诊断。
- [ ] 未知新建多维表格/素材的自动发现和经管理权限校验的认领修复工具；目前停止盲目重建，需要受控运维核对。
- [x] 退出时明确选择保留或清除应用当前副本；待同步/冲突存在时阻止清除，并先保存本机快照，不删除可见工作区和备份，不声称安全擦除。
- [x] 设备重命名接口及界面编辑入口。
- [x] 整库下载显示待下载图片数量、已知原始字节及当前 JSON 缓存预留估算；可用时显示浏览器容量估算，不伪造系统磁盘剩余。
- [ ] 压力下缓存逐出策略与客户端整库 JSON 的内存上限演练；未通过大规模题库基准，不能以小样本测试推断容量。
- [x] 同步诊断包含服务版本、应用类型、环境、协议、阶段和任务计数，可导出白名单诊断；不含用户身份、正文、图片、二维码或凭据。
- [ ] 手机实际相机、文件选择、扫码回流、键盘和无障碍检查；未以截图或模拟当成实机通过。

## 正式跨租户发布

- [ ] 平台允许的应用类型、服务商/商店资质及审批；个体工商户认证不等于自动获准商店发布。
- [ ] 安装、管理员授权、权限变更、卸载与撤销事件；验证事件签名、去重及生命周期，不接空成功回调。
- [ ] 不同租户/个人账号的实际资源归属、权限和附件管理能力。
- [ ] 从测试自建应用切换正式应用的身份关联、重新授权、旧库权限和附件验证，受控恢复流程；不能按昵称合并或只换 Secret。
- [ ] 网关数据库丢失/恢复、密钥轮换、多副本方案和监控告警；现有单实例模型不可直接并发多副本。
- [ ] 完成 A01–A25 真实验收，500 题/1000 图/2000 复习记录基准按真实额度执行并记录。
- [ ] 独立安全代码审查、依赖审核、完整备份恢复演练、隐私说明及服务运维职责。

尚未部署、未真实联调、未完成这些独立工作时，不要封装发布带“正式云同步已完成”承诺的安装包。现有纯本地版本的离线授权与数据能力仍独立存在。
