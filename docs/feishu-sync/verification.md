## 自动验证命令

```sh
npm test
GATEWAY_TEST_TRANSPORT=memory node --test tools/sync-gateway/*.test.mjs
npm run build
CARGO_INCREMENTAL=0 cargo test --manifest-path src-tauri/Cargo.toml --lib --offline
```

网关默认测试仍可用真实 localhost HTTP listener。工具额度限制阻止本轮最后启动新监听器，因此最终回归使用 `GATEWAY_TEST_TRANSPORT=memory`：它把请求流交给**真实网关处理器**，验证正文、Cookie、CSRF、Origin、权限、回调、错误等，不创建网络端口。更早版本确实执行过本机 loopback HTTP 测试，但这不等于最新代码经过公网/TLS，也不等于真实飞书。这里没有绕过监听器的权限限制。

四项互通集成测试使用真实 SyncRunner、现有 Notebook 校验、本地 JSON 持久化边界、SQLite 和 SyncService；**仅 Feishu Bitable/Drive 远端为测试替身**。已经由这类测试发现并修复撤销评分提交组未完成的问题。

## 自查决定与费用

这里的“费用”是改错后的工程/使用成本，不是新增云服务收费承诺。

- 沿用客户端原子 JSON / IndexedDB，新增同提交 outbox；避免先重写本地库，但大题库内存与复制成本必须实测。
- 并发复习保留事实、调度分歧交给用户；不静默改算法，成本是用户需要选择。
- 未知远端创建/上传结果停止盲目重试；避免重复记录/资源，成本是部分异常需要运维核对，目前完整修复工具未交付。
- 20 MiB 上传及 16 KiB 记录为本版明确限制；成本是部分已有超大内容只能继续本地使用，尚不能宣称完整覆盖所有题目。
- 正式跨租户模式硬阻断；成本是平台和代码生命周期工作完成前不能向所有购买者开放云功能。
